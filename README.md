# PlaceRise 🎓

A modern college placement management platform built for students and placement coordinators at Dev Bhoomi Uttarakhand University (DBUU).

---

## What is PlaceRise?

PlaceRise replaces the traditional WhatsApp + Google Forms + Excel workflow with a single, unified platform where students can browse and apply to placement drives, and coordinators can manage everything from one dashboard.

---

## Features

### Student Module
- Role-based login with ERP ID
- Multi-step onboarding — personal, academic, skills & resume
- Browse active company listings with eligibility filters
- View detailed JDs — tech stack, selection process, perks
- Apply to drives with a 3-application slot limit
- Track application status — Applied, Shortlisted, Selected, Rejected
- Profile management — edit personal & academic details
- Notification preferences & password management

### Coordinator Module
- Secure coordinator login
- Dashboard with real-time stats — placements, active companies, deadlines
- Full student database — searchable and filterable
- Company management — add companies, post & edit JDs
- Application management — view eligible students, manage application statuses
- Placement calendar — visual deadline tracker with company details
- Announcement board — create, publish, and manage announcements
- Profile & settings management
